Knowledge Base

Frequently Asked Questions

Everything you need to know about the CHARLO Testing Agent workstation, engines, and security model.

How does CHARLO differ from standard web vulnerability scanners? ▼
Standard scanners only look at live web pages. CHARLO is a multi-target workstation that audits Windows PE executables (ASLR, SafeSEH, section entropy), Android APK bytecode (AXML, cryptographic keys), GraphQL/WebSocket endpoints, and full-stack QA automation frameworks (Playwright, Selenium, WinAppDriver). In addition, CHARLO synthesizes unified code patches and exports official OASIS SARIF 2.1.0 reports.
Is my target code or scan data ever transmitted to cloud servers? ▼
No. CHARLO is engineered with a strict 100% offline, privacy-first architecture. All decompilation, binary analysis, AST parsing, and heuristic verification runs locally on your machine. No telemetry or target data leaves your environment unless you explicitly configure an outgoing webhook URL.
How does the Autonomous Code Auto-Patcher prevent breaking code? ▼
The Auto-Patcher uses Python Abstract Syntax Trees (AST) and verified pattern transforms rather than unstructured LLM text generation. Before writing any modification, CHARLO automatically creates an immutable .bak timestamped backup file, outputs a standard Unified Git Diff (.patch), and provides a one-click rollback mechanism.
Can CHARLO be integrated into GitHub Actions and GitLab CI/CD? ▼
Yes. CHARLO features a headless CLI mode (python main.py --cli ...). When run with --sarif results.sarif, it emits SARIF v2.1.0 output that natively populates GitHub Code Scanning alerts and GitLab Security Dashboards, with configurable quality gate exit codes.
What are the system requirements to run the desktop workstation? ▼
Windows 10/11 (64-bit), Python 3.10 or higher, and 4 GB RAM. PySide6 is used for GPU-accelerated rendering of the Cyber Crimson workstation GUI. Linux and macOS are also fully supported via terminal CLI mode.
